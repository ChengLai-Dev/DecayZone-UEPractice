`WBP_Tips` 控件树：

```
RootCanvas (CanvasPanel, SelfHitTestInvisible)
└─ Size_Tips (SizeBox, bAutoSize, 锚点 0.5/0.78)
   └─ Border_TipsOutline (Border, 1px 描边)
      └─ Border_TipsFill (Border, 20/10 内边距)
         └─ Text_Tips (TextBlock, 20px Bold, 居中)
```

已知问题（已确认的引擎行为）：

- `CreateWidget` 的 Owner 只接受 `UWidget` / `UWidgetTree` / `APlayerController` / `UGameInstance` / `UWorld`，`UUIManager`（`ULocalPlayerSubsystem`）不合法，当前代码编译不通过。
- `UDZ_Tips::StaticClass()` 创建的是 C++ 类实例，没有 WidgetTree，需要改用 WBP 类（`TSubclassOf`）。

需求（用户已确认）：允许叠加显示，每次调用创建独立实例，展示 `Duration` 秒后自行销毁。

动画方案未定，取决于插件改造进度（见第 5 节）。

## 5. 外部依赖：WidgetJsonBridge 动画支持

需求：让插件支持从 JSON 生成 `UWidgetAnimation`（双向同步）。

当前状态：插件只同步 WidgetTree，不处理 `Animations`。插件重建树时**不会销毁**已有动画（`WidgetJsonSync.cpp` 约 345 行把动画名加入 `LiveVariableNames` 保护 GUID），但 JSON 无法描述动画，也无法从 JSON 重建动画资产。

此项由用户安排其他会话完成，完成后 `WBP_Tips` 的淡入淡出才能改为 `PlayAnimation`。
