# SM_ExtractionPlatform_01 · 资产说明

撤离点圆形工业平台，占位级（功能优先，不追求精细）。

## 规格

| 规格项 | 取值 |
|---|---|
| 类型 | 静态网格（无动画、无骨骼、无 LOD） |
| 直径 | 600.0 cm（X 600.1 / Y 599.8，椭圆度 0.05%） |
| 厚度 | 30.0 cm |
| 锚点 | 几何原点在圆盘**底面中心**，最低点 Z = 0 |
| 朝向基准 | 正面朝 +Z。水平方向旋转对称，无需朝向基准 |
| 三角面 | 631,656（Nanite 开启） |
| 材质 | 1 个：`M_ExtractionPlatform_01`，单材质槽 `Platform` |
| 贴图 | `T_ExtractionPlatform_01_BC` / `_N` / `_ORM`，4096²，shared:wrap |
| 碰撞 | 无 |
| 命名 | 遵循项目前缀 `SM_` / `M_` / `T_` |

## 材质构成

- **BaseColor** ← `_BC`
- **Normal** ← `_N`
- **Metallic / Roughness / AO** ← `_ORM` 的 B / G / R
- **Emissive** ← `_BC` × `saturate((G+B)/2 − R)` × 4.0
  —— 用"青绿比红高多少"当遮罩，把边缘发光带从基础色里挑出来单独发光，不需要第四张贴图。
- Two-Sided = true（继承 glTF 的双面设置）
- 自发光强度 4.0 是估计值，**未在编辑器内目视验收**。过曝就调这个常量。

## 生产路径

1. FLUX 3 Klein 出 3/4 俯视概念图（seed 7702，1024²，16 步）。
2. Pixal3D 单图生 3D（seed 7702，约 193s，GLB 42MB / 70 万面）。
3. `tools/fix_platform.py`：PCA 拟合盘面 → 裁掉背侧虚构支架 → 转到 +Y up → 归一化到 φ6.0m × 0.3m → 原点归到底面中心。
4. `tools/ue_build_platform.py`：无头导入 → 贴图重命名 → 建材质 → 赋材质 → 开 Nanite → 保存。

详细参数与提示词见 `Assets.md`。

## 已知瑕疵

| 瑕疵 | 程度 | 影响 | 处置 |
|---|---|---|---|
| **底面（背面）贴图是虚构的** | 明显 | 底面是一层粉/青噪点，不是金属；底面还留有少量未封口的残桩 | 地面放置时不可见。若要悬空展示，需要另做底面材质 |
| **盘面轻微起伏** | 轻微 | 侧视看盘面有 ±1~2cm 的低频鼓起 | 单图深度场的固有误差。可接受；要平就得重建或手工找平 |
| **细节偏软** | 轻微 | 6m 直径摊 4096 贴图 ≈ 6.8px/cm，近看铆钉发糊 | 占位级可接受 |
| **发光带不是独立几何** | 轻微 | 发光靠贴图 + 自发光遮罩实现，斜看边缘有贴图拉伸，不会真的"溢出"到空气里 | 需要真实光带时加一圈环形网格 + Emissive 材质 |
| **厚度不是重建出来的** | 中性 | 30cm 是后处理归一化的结果，不是模型自己算出来的 | 厚度准确但盘身侧面细节同样偏软 |
| **圆盘边缘有极少量接缝** | 轻微 | 外缘一圈少数三角形法线朝内，双面材质掩盖了大部分 | 占位可接受 |
