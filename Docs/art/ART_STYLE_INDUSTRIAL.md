# 美术规范 · 工业金属道具与场景件

适用范围：`Content/Assets/Props/` 下的工业/废墟风硬表面资产（平台、箱子、机械件、建筑外立面）。
本规范只约束**表现层**；尺寸、格式、命名、锚点等技术规格以 `docs/contracts/assets.md` 为准（该文件当前不存在，见 `Docs/art/questions/20261112-missing-assets-contract.md`）。

## 1. 配色（sRGB 基础色，写进 T_*_BC）

| 规格项 | 取值 | 说明 |
|---|---|---|
| 钢件基色 | `#575B61` 附近（0.34, 0.36, 0.38） | 中性偏冷灰，禁用暖灰，避免与木质道具混淆 |
| 深凹槽/缝隙 | `#212327` 附近 | 只用于沟槽、拼缝、铆钉阴影 |
| 锈色 | `#61381F` 附近，覆盖率 ≤ 15% | 只沿凹槽/警示带边缘渗色，不做全身锈 |
| 警示色（黄） | `#B88C29` 附近，饱和度不超过 0.72 | 只用于边缘警示环/条纹 |
| 发光青绿 | RGB(0.35, 0.95, 0.88) | 撤离点、能源类交互件的主发光色 |
| 发光琥珀（备选） | RGB(1.00, 0.62, 0.18) | 危险类/待激活状态 |
| 背景填充（图集空白区） | 基色 × 0.75 | 防止 mip 边缘渗色发亮 |

## 2. PBR 数值

| 规格项 | 取值 | 说明 |
|---|---|---|
| 金属度（钢） | 0.85–0.92 | 低于 0.8 会显得像塑料 |
| 金属度（漆/警示色） | 0.0–0.10 | 油漆是电介质，必须压到接近 0 |
| 粗糙度（钢面） | 0.55–0.70 | 低于 0.5 在本项目光照下会过曝 |
| 粗糙度（铆钉/亮边） | 0.30–0.40 | 只用在凸起件，制造对比 |
| 粗糙度（凹槽） | 0.75–0.85 | 沟槽里更脏更哑 |
| AO（ORM 的 R） | 凹槽 0.60–0.70，边缘 0.55–0.80，其余 1.0 | 不要烘焙过重，UE 还有 SSAO |

## 3. 贴图与 UV

| 规格项 | 取值 | 说明 |
|---|---|---|
| 图集尺寸 | 1024²，三张（BC / N / ORM） | BC 用 RGB，ORM 用 R=AO G=Rough B=Metal |
| 顶点密度 | 顶面（主视面）≥ 70 万像素/㎡ | 即 1024 图集里主视面占 0.72×0.72 区域 |
| 侧面带宽 | 沿周向重复 6 次 | 重复次数太少会出现单条可见接缝 |
| 法线尺度 | 高度梯度 × 20~30 | 超过 35 会出现"塑料浮雕"感 |
| 法线约定 | OpenGL（+Y 向上）写出 | UE Interchange 导入会自动 `flip_green_channel=True`，不要手改 |

## 4. 造型规则

| 规格项 | 取值 | 说明 |
|---|---|---|
| 顶面外缘倒角 | 1.5–2.5 cm | 杜绝 90° 硬边，硬边在光照下会出亮线 |
| 发光带做在哪 | 独立几何环，抬高 1mm | 不做纯贴图发光；抬高 1mm 防 z-fighting |
| 站点面高差 | 0（可行走面必须平整） | 视觉凹槽一律用法线贴图表现，不切几何 |
| 圆周分段 | ≥ 96 | 60 段以下大圆盘边缘能看出折线 |
| 背面剔除 | 开（Backface Culling） | 单面墙体/平台一律单面渲染 |

## 5. 授权与来源

| 规格项 | 取值 |
|---|---|
| 允许的贴图来源 | 本地 FLUX 3 Klein 生成（年营收 < $5M）、本地 MOSS（Apache-2.0）、程序化生成 |

| 记录要求 | 每件资产在 `ASSET_MANIFEST.md` 记模型/提示词/种子，在 `LICENSE_LIST.md` 记授权结论 |
